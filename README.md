## ⚡ About Me
I design and engineer modern Android applications where **performance**, **visual polish**, and **user privacy** aren't afterthoughts—they're the foundation. 
Right now, I'm building **[Wave Zone](https://github.com/wix0x1/Wave-Zone-Releases)**, a high-performance, zero-telemetry media client and downloader for Android crafted entirely with Kotlin and Jetpack Compose.
* **Architecture-First:** Strict separation of concerns using Clean Architecture, MVI/MVVM, and reactive data streams.
* **Design-Driven Engineering:** Translating frosted-glass aesthetics (glassmorphism), warm color palettes, and fluid micro-interactions into native Compose UI.
* **Uncompromising Privacy:** Building software with zero third-party trackers, zero analytics bloat, and complete local user control.

### 🏗️ Under the Hood

| Layer | Technologies & Patterns | Engineering Focus |
| :--- | :--- | :--- |
| **UI & Design** | `Jetpack Compose` • `Material 3` • `Custom Canvas/Blur` | Declarative UI, smooth 120Hz animations, glassmorphic surfaces |
| **Architecture** | `Clean Architecture` • `MVVM / MVI` • `Unidirectional Data Flow` | Decoupled domain logic, predictable state management |
| **Async & Data** | `Kotlin Coroutines` • `StateFlow` • `WorkManager` | Resilient background downloading & reactive state updates |
| **Privacy & Security** | `Zero-Telemetry` • `Local-First Storage` | Complete absence of analytics or third-party tracking SDKs |
